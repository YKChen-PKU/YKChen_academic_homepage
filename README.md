# Yan-Ke Chen — academic homepage

Static personal homepage with an INSPIRE-HEP analytics dashboard.

## Quick start

```bash
# Refresh INSPIRE data
python scripts/fetch_inspire.py

# Build & preview the site
cd site && npm install && npm run dev
```
